Labeled text field with warm focus ring — booking forms, contact, search.

```jsx
<Input label="성함" placeholder="홍길동" />
<Input label="연락처" prefix="📞" hint="예약 확인 문자가 발송됩니다" />
<Input label="이메일" error="올바른 형식이 아니에요" />
```

Props: `label`, `hint`, `error`, `prefix`, `size` (md/lg). Forwards all native input attrs.
