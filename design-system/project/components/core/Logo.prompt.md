The Mellowbrow wordmark — use in headers, footers, loaders.

```jsx
<Logo variant="full" size={26} />
<Logo variant="stacked" size={34} />
<Logo variant="mono" size={44} />        {/* circular 'm' avatar mark */}
<Logo color="var(--paper)" />            {/* on dark surfaces */}
```

Variants: `full`, `stacked` (with tagline), `mono` (circular badge). Set `color` for dark backgrounds.
