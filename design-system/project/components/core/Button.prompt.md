Soft pill call-to-action in warm mocha — use for booking, primary actions; one per view.

```jsx
<Button variant="primary" size="lg">예약하기</Button>
<Button variant="secondary">서비스 보기</Button>
<Button variant="ghost" size="sm">자세히 →</Button>
```

Variants: `primary` (mocha fill), `secondary` (outlined card), `ghost` (text only), `quiet` (soft tint). Sizes `sm | md | lg`. Props: `pill` (default true), `full`, `iconLeft`, `iconRight`, `disabled`.
