Menu card for one brow service — photo, KO/EN name, price, duration.

```jsx
<ServiceCard titleKo="자연눈썹" titleEn="Natural" tag="시그니처"
  description="결을 한 올씩 살린 가장 자연스러운 디자인."
  price="₩250,000" duration="약 2시간 · 리터치 포함" onSelect={...} />
```

Pass `image` for a real photo (else warm placeholder). Use in a 3-up grid on the services page.
